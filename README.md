# Vocal portfolio

Локальная статическая презентация. Сборка и зависимости не нужны.

Открыть:

```sh
python3 server.py
```

Затем перейти на [http://localhost:8080](http://localhost:8080).

`server.py` поддерживает HTTP Range, необходимый для перемотки аудио и видео.
Обычный `python3 -m http.server` на установленной версии Python отдает файлы
только целиком, поэтому ползунок плеера работает некорректно.
